# 动作识别实施路线（当前素材版）

## 结论

同一张抽帧图片可以同时用于器具检测和动作观测，但它不是同一种标注。

- 器具检测：一张图片对应 YOLO 18 类器具框。
- 动作观测：一段视频对应动作 ID、正例/错误/困难负例、起止时间和证据帧。
- 姿态关键点：少量关键帧额外标注器具的 3 个关键点。

因此，不能把“温杯洁具”“投茶”“注水”等名称加入 YOLO 的类别。YOLO 只回答“器具在哪里”；动作规则再判断“哪些器具以什么顺序、位置和时间发生关系”。

统一清单由 `scripts/build_multitask_workspace.py` 生成到：

```text
dataset/tea_multitask_v1/
```

它只引用原始图片和标签，不复制数据，也不会破坏已经完成的标注。

## 器具检测模型

本轮刚完成的模型是 `YOLOv8n`：

```text
models/low_vram/front_detect_reviewed_stage1_640/weights/best.pt
```

它训练使用的发布集是：

```text
dataset/tea_sop_front_v1/releases/detection/front_detect_reviewed_v1
```

该发布集共有 1,238 张：train 868、val 321、test 49。早期 `YOLO26n` 的 `current10` 和盖碗实验模型应保留作对照，不要与本轮 YOLOv8n 权重混用。

下一次检测模型发布应在完成以下操作后进行：

1. 将 `tea_dataset_v1_reviewed` 的 844 张 accepted 图像和当前发布集做感知相似度去重。
2. 以完整原视频 session 分配 train/val/test，不继承随机的旧 split。
3. 侧面数据可以单独训练侧面补充模型，或仅进入 front 模型的 train 增强池；绝不进入 front val/test。
4. 新增的正面流程图只有在器具框审核完成后才进入检测训练；动作标签本身不能替代器具框。

## 动作识别实施顺序

当前不训练“动作分类 YOLO”。先用已有代码中的器具检测、ByteTrack、MediaPipe Hands/Pose、规则和状态机完成第一版。

1. 整理时间段
   - 完成 `dataset/tea_multitask_v1/manifests/action_segments_review.csv` 的每个动作起止时间。
   - `new_front_full_202608` 中的正面流程素材属于训练/规则调参素材，不作为本次正式 holdout。
   - 当前正式 holdout 固定为 `已加速- IMG_4901.MOV` 的抽帧：该视频的抽帧只能分配到 val/test，不能进入 train。
   - IMG_4901 的抽帧完成器具框人工审核后，才发布正式 val/test；训练集继续使用其余场景。

2. 先验收不依赖壶/关键点的动作
   - 品茗杯一字型、品字型和不规范布局：品茗杯框中心几何 + 一秒稳定窗口。
   - 双手托举茶荷：茶荷框 + MediaPipe 双手相对两侧 + 离桌 + 持续时间。
   - 开盖闻香：碗身/碗盖分离 + 鼻部距离 + 持续时间。
   - 取茶到茶荷：茶叶罐、茶荷、手的时序关系。它只能判断规范转移姿态，不能证明茶叶实际进入。

3. 标注关键点并实现倾倒类动作
   - 只从 `water_injection`、`tea_lotus_to_gaiwan`、`gaiwan_to_pitcher`、`tea_distribution` 中选择状态变化明显的 800 至 1,200 帧。
   - 烧水壶：壶嘴、壶身中心、手柄中心；公道杯：出水口、杯身中心、手柄中心；盖碗和茶荷同样各 3 点。
   - 用 YOLOv8n-pose 训练关键点；代码根据连线计算倾斜和出水端是否进入目标器具区域。

4. 形成 SOP 事件
   - 温杯洁具：烧水壶到盖碗、公道杯、品茗杯，再到建水的有序事件。
   - 投茶：茶荷到盖碗的倾倒姿态事件。
   - 注水：壶嘴到盖碗区域、壶体倾斜和持续时间。
   - 冲泡计时：盖合完成到出汤开始的单调时间差，判断 8 至 12 秒。
   - 出汤：盖碗到公道杯的倾倒关系。
   - 分茶：公道杯依次对准不同品茗杯，检查方向和不重复轨迹。

5. 最后才训练时间序列动作模型
   - 仅当某个规则在独立正面验证视频中达不到 Precision 0.90、Recall 0.85 时，才把该动作的连续帧片段训练为轻量时序分类器。
   - 不在当前阶段把大量相邻抽帧直接作为独立“动作图片”训练；那会造成时间泄露并让模型记住背景。

## 近期拍摄和标注要求

- `new_front_full_202608` 正面流程：继续作为正面正例和器具遮挡检测训练数据，但不进入本次 IMG_4901 holdout。
- `已加速- IMG_4901.MOV`：只作为本次检测 val/test 候选，不能把其中任何图片复制回 train。
- 侧面托举、闻香正负例：保留给动作规则调参与后续 pose，不混入正面正式测试。
- 下一次拍摄优先补正面 `error` 和 `hard_negative`：错序温杯、只靠近不倒入、单手拿茶荷、打开碗盖但不闻香、直立壶靠近盖碗、出汤目标错误、分茶重复/乱序、不规范杯位。
- 每个新 session 只归入一个 split；计划至少新增一个正面 val session 和一个正面 test session。
