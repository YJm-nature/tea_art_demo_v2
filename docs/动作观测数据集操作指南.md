# 动作观测数据集操作指南

动作数据与现有 848 张茶具检测图片分开保存。茶具图片继续训练器具检测模型；动作片段用于规则和状态机验收；手部饰品 ROI 单独训练 3 类 nano 检测模型。不要给茶具图片追加动作类别，也不要改变现有 18 类茶具编号。

## 1. 初始化与目录

项目已经包含空数据集 `dataset/action_observations_v1`。需要创建另一个版本时运行：

```powershell
python scripts\action_dataset.py init dataset\action_observations_v2
```

主要目录：

```text
action_observations_v1/
  raw_sessions/<session_id>/<tabletop|side>/videos/
  annotations/segments.jsonl
  splits/session_assignments.csv
  schemas/
  templates/
  jewelry_roi/{train,val,test}/{images,labels}/
  jewelry_roi/manifest.jsonl
```

一次连续录制使用一个稳定的 `session_id`。同一次录制的桌面和侧面视频必须使用相同 `session_id`，且整个 session 只能属于一个 split。

## 2. 标注动作片段

先在 `splits/session_assignments.csv` 登记 session：

```csv
session_id,split
session_20260730_001,train
```

视频按以下方式放置：

```text
raw_sessions/session_20260730_001/tabletop/videos/main.mp4
raw_sessions/session_20260730_001/side/videos/main.mp4
```

逐行向 `annotations/segments.jsonl` 写入 JSON 对象。直接参照 `templates/action_segment.example.jsonl`，不要用表格软件编辑 JSONL。关键字段如下：

| 字段 | 含义 |
|---|---|
| `segment_id` | 全数据集唯一的片段编号 |
| `session_id` / `split` | 录制 session 及其固定划分 |
| `camera_role` | `tabletop` 或 `side` |
| `observation_point_id` | 固定使用 `result_cup_layout`、`action_hold_lotus`、`action_open_lid_smell`、`action_hold_tray` 等运行时 ID |
| `start_ms` / `end_ms` | 相对视频起点的整数毫秒时间 |
| `sample_kind` | `positive`、`error` 或 `hard_negative` |
| `target_utensil` | 英文器具 key；无器具时为 `null` |
| `review_status` | `pending`、`needs_fix`、`accepted` 或 `rejected` |

`error` 表示明确做错的动作；`hard_negative` 表示很像目标动作但实际上没有执行，例如双手短暂经过茶荷。二者不要混用。审核状态不是 `pending` 时，必须填写 `reviewer` 和带时区的 `reviewed_at`。

## 3. 标注手部饰品 ROI

MediaPipe 产生的手和手腕裁剪图放入 `jewelry_roi/<split>/images`，YOLO 标签放入相邻 `labels`。固定类别不可调整：

```text
0 ring
1 bracelet_or_bangle
2 watch
```

每张 ROI 都必须在 `jewelry_roi/manifest.jsonl` 登记，格式参考 `templates/jewelry_roi.example.jsonl`。裸手和反光茶具等负样本也必须创建同名的空 `.txt` 标签；裸手负样本建议不少于全部 ROI 的 40%。同一原视频产生的所有 ROI 必须继承原视频的 `session_id` 和 split。

## 4. 每次提交前校验

采集和标注阶段允许原视频尚未复制到数据集，缺失视频只产生 warning：

```powershell
python scripts\action_dataset.py validate dataset\action_observations_v1
```

正式冻结版本时强制检查视频存在，并保存报告：

```powershell
python scripts\action_dataset.py validate dataset\action_observations_v1 `
  --require-media `
  --report output\action_dataset_validation.json
```

返回码为 0 且报告中 `valid: true` 才能用于验收或训练。校验会检查 JSONL 必填字段、时间范围、审核信息、路径、YOLO 归一化框、重复 ID、文件配对和 session 跨集合泄漏。

## 5. GTX 1060 6GB 饰品训练

先对少量样本进行 3 epoch 冒烟训练：

```powershell
yolo detect train cfg=dataset\action_observations_v1\jewelry_roi\train_6gb.yaml epochs=3 name=jewelry_smoke
```

冒烟训练正常后执行正式训练：

```powershell
yolo detect train cfg=dataset\action_observations_v1\jewelry_roi\train_6gb.yaml
```

配置固定为 `yolo26n.pt`、`imgsz=512`、`batch=4`、`workers=0`、`cache=false` 和 AMP。显存不足时依次覆盖为 `batch=2`、`batch=1`，不要同时训练茶具模型。正式模型必须使用独立 test，门槛为 Recall 不低于 0.95、Precision 不低于 0.90。
